# End to end tests

we end to end test to maintain code quality and ensure that the application is working as expected.we need to run tests using Playwright for our main features 

### Requirements
- install playwright 
- the test should be able to run using `pnpm run test:e2e`
- use separate database for testing
- use playwright mcp server
- keep tests DRY,modular and easy to maintain
- follow best practices for testing
- create proper docs for the tests
